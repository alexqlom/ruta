# Ruta

App gratuita para preparar el examen teórico de conducir en Chile, con lecciones cortas al estilo Duolingo, para todas las clases de licencia (A1 a A5, B, C, D, E y F).

- **Más de 1.000 preguntas** de 16 tipos: alternativas, verdadero o falso, unir, ordenar, armar frases, tocar en la imagen, videos animados, percepción de riesgos y más.
- **Simulacros** del examen, contrarreloj y guía de búsqueda.
- **Simular**: 11 juegos con controles táctiles (pedales, volante, cambios y palancas) y 32 misiones: auto automático y mecánico, estacionar, moto, bus, camión articulado, excavadora, grúa horquilla, carreta y vehículo de emergencia.
- Estilo minimalista negro y rojo, funciona sin conexión y guarda el progreso en el dispositivo.

Las preguntas se basan en la Ley de Tránsito (Ley 18.290) y en material de CONASET. No es una aplicación oficial.

## Uso

Es una app web estática: abre `index.html` desde cualquier servidor (por ejemplo, `python3 -m http.server`) o publícala con GitHub Pages.

## App Android

La carpeta `android/` tiene un envoltorio nativo mínimo para generar el APK. Revisa `android/README.md`. La firma (`*.keystore`) no se sube al repositorio.
